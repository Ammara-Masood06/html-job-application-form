# 📝 Responsive Job Application Form

A clean, modern, and fully responsive job application form built as a capstone project for the **Introduction to HTML** course on Simplilearn. 

## 🚀 Features
* **Semantic HTML5 Structure:** Built using proper semantic elements and accessibility attributes (`for`, `id`, `required`).
* **Modern CSS Grid Layout:** Features a flexible, multi-column form structure that adapts seamlessly to different screen sizes (`auto-fit`, `minmax`).
* **Interactive Elements:** Includes standard input fields, dropdown menus (`<select>`), textareas, file upload controls, and date pickers.
* **Responsive Design:** Includes media queries to collapse layouts on smaller mobile screens (<460px).
* **Hover & Focus Effects:** Styled with custom CSS gradients, smooth transitions, and interactive button feedback.

## 🛠️ Built With
* **HTML5**
* **CSS3** (Flexbox & CSS Grid)
